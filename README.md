# Prodigy InfoTech — Data Science Internship

This repository contains the tasks completed during my 1-month Data 
Science Internship at **Prodigy InfoTech** (September 2026).

## Tools & Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn

## Tasks

### Task 01: Data Visualization — Population Distribution
Visualized population distribution across countries using a histogram, 
and India's population trend over time using a bar chart.

📁 [View Task 01 Notebook](https://github.com/khushiyadav47/Prodigy-InfoTech-Internship/blob/main/PRODIGY-DS-task01.ipynb)

### Task 02: Data Cleaning & Exploratory Data Analysis — Titanic Dataset
Performed data cleaning (handled missing values in Age, Cabin, and 
Embarked; engineered new features like Title, FamilySize, IsAlone, 
and Has_Cabin) and exploratory data analysis on the Titanic dataset 
to uncover patterns in passenger survival. Key findings include the 
strong influence of Sex, Passenger Class, and Age on survival rate, 
along with correlation analysis and visualizations (bar charts, 
histograms, and a correlation heatmap).

📁 [View Task 02 Notebook](https://github.com/khushiyadav47/Prodigy-InfoTech-Internship/blob/main/PRODIGY-DS-task02.ipynb)
